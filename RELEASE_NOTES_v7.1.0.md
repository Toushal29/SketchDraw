# SketchDraw 7.1.0 / Android 2.0.0

This release brings a refreshed Windows and mobile workspace, richer editable text cards, and fixes across drawing, canvas patterns, recent files, and layout.

## Added and improved

- Added an editable Markdown text tool with Markdown tables, table insertion and editing, and conversion between plain text and Markdown cards.
- Added view-only opening for `.sketch` files. The laser pointer remains available, and note, sticky-note, checklist, and other collapsible cards can still be expanded or collapsed.
- Added a pen and paint-brush thickness setting that uses either preset sizes or whole-number fine tuning with step buttons, a slider, and a preview. Font sizes and thicknesses use whole numbers.
- Added portrait and landscape mobile/tablet layouts with responsive toolbars, orientation settings, and quick style controls.
- Updated the Windows toolbar, contextual Properties panel, collapsed note cards, and Android launcher icon.

## Fixed

- Improved stroke continuity for Windows drawing and stylus input; tapping with the pen or a brush creates a visible dot.
- Fixed recent-file history persistence across app restarts.
- Corrected paper-pattern previews and isometric grid alignment.
- Fixed end arrowhead selection on forked arrows and arrow overlap with double-line strokes.
- Improved mobile popup positioning, including panels clipped at landscape screen edges.
- Fixed the blank white startup screen and refined compact/collapsed note, sticky-note, and checklist cards.

## Downloads

- Windows x64 installer and standalone executable.
- Universal Android APK, version 2.0.0.

SketchDraw continues to save version 7 `.sketch` documents.
