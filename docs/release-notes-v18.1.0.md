# SketchDraw 18.1.0 (Windows) / 18.1.0 (Android)

## New and updated

- Refresh the toolbar, inspector, style pane, full inspector, view settings, and foundation elements with an Apple-inspired visual design.
- Add smart distance guides that show gaps between objects while dragging.
- Locking or unlocking a layer group now cascades to its descendant layers.
- Fix the Windows style pane remaining visible when no element is selected.
- Extract dialog state and schema insertion into dedicated modules.
- Refine theme picker button interactions.

## Compatibility

- Windows version: `18.1.0`.
- Android version: `18.1.0` (version code `18001000`).
- Canvas documents use `.sketch` format version 3; Planning files use `.sdplan` version 1; UI Design files use `.sdui` version 1.
- The GitHub release workflow builds the signed Windows updater bundles and arm64 Android APK.
