# SketchDraw 12.3.0 (Windows) / 7.3.0 (Android)

## What's new

- Rebuilt light and dark colors around a shared theme palette.
- Refreshed the home screen with a canvas preview and a more visible, theme-aware background.
- Added print-ready PDF export alongside PNG and SVG export.
- Added project planning views for tasks, milestones, schedules, decisions, risks, and reference files.
- Added a visible installed-version label below the update control in Help and updates.
- Reduced the accent and toolbar color choices to compact swatches.
- Removed canvas rulers and their controls; the ruled paper pattern remains available.

## Improvements

- Reduced repeated document serialization during saves and improved Windows file-sync observation work.
- Improved Android stylus input by reusing view measurements during batches of pen samples.
- Reduced live pen rendering work; previews now extend a cached path, while the pressure outline is generated once when the stroke ends.
- Simplified drawing background and canvas controls for a steadier layout.
- Updated the Android version code to 7030000.

## Downloads

- Windows: signed SketchDraw installer and updater artifacts attached to the GitHub release.
- Android: signed arm64 APK attached to the GitHub release.
