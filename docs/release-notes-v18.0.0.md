# SketchDraw 18.0.0 (Windows) / 18.0.0 (Android)

## New and updated

- Add pressure curve editing, stroke dynamics, symmetry drawing, ghost layers, and automatic path closing to Canvas.
- Add an infinite clipboard tray, drawing challenges, spatial file browsing, ambient canvas motion, a canvas soundtrack, visual effects controls, and color sample history.
- Redesign the radial context menu with larger submenu targets and a delayed close when moving between menu rings.
- Organize view settings into Appearance, Canvas, Drawing tools, Experience, Accessibility, and Document sections.
- Consolidate duplicate component styles and adjust the full inspector to use the available viewport height.
- Keep standalone Markdown tables compact and snap fine-grid moves to the visible 25-unit spacing.

## Compatibility

- Windows version: `18.0.0`.
- Android version: `18.0.0` (version code `18000000`).
- Canvas documents use `.sketch` format version 3; Planning files use `.sdplan` version 1; UI Design files use `.sdui` version 1.
- Windows updater bundles and the Android APK are signed by the GitHub release workflow.
