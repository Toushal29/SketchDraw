# SketchDraw 16.0.0 (Windows) / 11.0.0 (Android)

## What's new

- Remastered `.sketch` documents now save as format version 2. SketchDraw can open legacy versions 9 and 10 and offers an explicit conversion before replacing an older file.
- Added a separate `.sdplan` workspace for project notes, tasks, milestones, decisions, and reference files.
- Reworked chart editing around ECharts, with more chart types, editable data, and live graph updates.
- Expanded diagram guides and examples, and improved UML and flowchart connectors, labels, and rendering consistency.
- Improved canvas sharpness at 100% zoom and updated the Canvas/Planning switcher placement on the Welcome screen.

## Compatibility

- Windows version: `16.0.0`.
- Android version: `11.0.0` (version code `11000000`).
- New `.sketch` files use format version 2. Legacy `.sketch` versions 9 and 10 can be opened and converted after confirmation.
- `.sdplan` format remains version 1.
- Windows updater bundles and the Android APK are signed by the GitHub release workflow.
