# SketchDraw 15.0.0 (Windows) / 10.0.0 (Android)

## What's new

- Added default 10-unit movement snapping, adjustable in Canvas settings, with Ctrl or Command bypass for freehand movement and alignment guides against nearby objects.
- Reorganized Canvas settings so canvas aids are first and common actions are easier to find.
- Refined ER and UML component rendering, including compact notation symbols, component-sized bounds, and black-and-white default ER styling.
- Simplified and repositioned the mobile properties pane to fit the available screen space without horizontal scrolling.

## Compatibility

- Windows version: `15.0.0`.
- Android version: `10.0.0` (version code `10000000`).
- `.sketch` format remains version 10; `.sdplan` format remains version 1.
- Existing Android signing and Windows updater signing are handled by the GitHub release workflow.
