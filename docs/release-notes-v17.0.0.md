# SketchDraw 17.0.0 (Windows) / 12.0.0 (Android)

## What's new

- Expanded editable modeling workflows across Mermaid families, PlantUML subsets, D2, BPMN, SQL schemas, cloud architecture, and data lineage.
- Added and refined shape catalogs, reusable component libraries, stencils, charts, and connector editing.
- Improved canvas input, rendering performance, selection behavior, and mobile touch controls; advanced mobile tools remain available from compact menus.
- Refined the Windows canvas header and toolbar placement so the tool controls remain clear of the document header.
- Added the AI appearance theme and refreshed workspace styling.

## Compatibility

- Windows version: `17.0.0`.
- Android version: `12.0.0` (version code `12000000`).
- New `.sketch` files use format version 2. Legacy `.sketch` versions 9 and 10 can be opened and converted after confirmation.
- `.sdplan` format remains version 1.
- Windows updater bundles and the Android APK are signed by the GitHub release workflow.
