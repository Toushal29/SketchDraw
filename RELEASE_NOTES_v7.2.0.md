# SketchDraw 7.2.0 / Android 2.2.0

This release improves drawing responsiveness, expands Android file access, and adds a more adaptable mobile/tablet workspace.

## Added and improved

- Added Android document-picker support so sketches can be opened and saved through system-provided storage locations. Added an Android setting that opens the system page for optional all-files access.
- Added a saved mobile/tablet toolbar position setting for top, bottom, left, or right. Tool lists scroll along the selected edge, and quick-style controls remain available.
- Refined mobile/tablet View and Gestures popovers and dark-theme component styling.

## Fixed

- Improved crowded-canvas rendering by drawing visible elements and reusing stroke paths during redraws.
- Improved stylus stroke continuity by consuming coalesced pointer samples and preserving the terminal point.
- Fixed Android document naming and saving behavior for multiple untitled sketches.
- Improved moving and snapping elements while keeping connector bindings aligned.

## Downloads

- Windows x64 installer and standalone executable.
- Universal Android APK, version 2.2.0.

SketchDraw continues to save version 7 `.sketch` documents.
