# SketchDraw

`This app is made entirely using AI. Use at your own risk.`

SketchDraw is a desktop-first, offline-first design app for Windows, macOS, and Linux, with a lightweight Android companion. Its shared app shell routes to three separate workspaces: Canvas for drawings and diagrams (`.sketch`), Planning for notes and project records (`.sdplan`), and UI Design for interface mockups (`.sdui`). Each workspace keeps its own document session and data model, so you can switch between them without converting or merging files. Save locally or in a folder managed by OneDrive, Dropbox, Google Drive, or another sync service.

UI Design has a welcome screen with create/open actions, recent .sdui files, draft recovery, and a route back from the editor. Its contextual right inspector separates Design, Prototype, and Inspect; selection-specific controls stay with the selected layer, while the local token library remains in a distinct Design section. Its multi-page infinite canvas supports screen and container frames, shared nested layers with drag-and-drop stacking, before/after placement, grouping and ungrouping by reparenting, transparent groups, nested auto layout with fixed, fractional, and minmax grid tracks, editable responsive breakpoints managed alongside Frames in the Pages panel and side-by-side frame previews, local components with nested variants, master updates, and per-child overrides, mode-aware color/typography/spacing/radius/effect tokens with editable aliases across all token families and cycle-safe import validation, prototype preview, and SVG/PNG/PDF export. Inspect / Handoff provides SVG, PNG, multi-screen PDF, offline HTML presentation, token, accessibility-report, and CSS/HTML/SolidJS scaffold exports. The compact asset grid includes editable basics and searchable UI patterns, with component-library import/export. This workspace uses a separate .sdui version 1 format. Current limits include browser-level interaction coverage for nested components, advanced vector operations, and full multi-platform review. See the [UI Design development plan](docs/ui-design-development-plan.md) for verified behavior and the current backlog.

PlantUML imports and exports have documented editable subsets for activity, state, use-case, component, deployment, timing, mind map, WBS, Gantt, nwdiag network, JSON/YAML, and common ArchiMate declarations and relationships, alongside the existing class/object and sequence subsets. The editor shows supported syntax and known limits; advanced-family syntax errors include line and column information. Mapped text-label edits update retained source, while free canvas positions and added or deleted objects are not serialized.

**App versions: Windows 17.1.0 | Android 17.1.0 | Document format: v3 | Copyright (c) 2026 Toushal Sampat**

> SketchDraw saves version 3 .sketch documents for Canvas, version 1 .sdplan documents for Planning, and version 1 .sdui documents for UI Design. The UI Design parser rejects older or unknown schemas rather than silently migrating them. It reads version 2 sketches and migrates old Forms & UI component IDs and properties into the version 3 component record. Legacy .sketch versions 9 and 10 require confirmation before conversion; declining closes the source without saving. Earlier versions are unsupported. Canvas and Planning documents remain open when you switch workspaces. With a sketch open, a second navigation group switches between Canvas and Diagram tools within the Canvas workspace.

## Features

- **Quick text styling:** Adjust text size from the quick-style rail, then open its text-style popover for Bold, Italic, Underline, and all six supported font families.
- **Text wrapping:** New and edited canvas text wraps within a 240-unit text box; shape and connector labels wrap to their available label area. Editing, selection bounds, canvas rendering, and SVG/PDF export share the same wrapped lines.
- **File menus:** File holds sketch and plan create, open, save, rename, and close actions. The separate Import / Export menu groups image, PDF, draw.io, editable diagram/code, web embed, and document export actions.
- **Keyboard shortcuts:** On Windows, Help and F1 open one searchable shortcut view with editable assignments and fixed shortcuts together. Other platforms keep the reference-only shortcut list.
- **Precision tools:** Use **M** to measure between selected canvas objects or drag between two canvas points; the object measurement shows axis gaps, nearest distance, alignment, and equal spacing. **Escape** leaves measure mode. Snapping uses the configured grid, object alignment, equal-spacing targets, and one-pixel free-move/resize precision; hold **Ctrl** or **Command** to bypass snapping, and hold **Shift** to constrain movement to one axis, release resize snapping and aspect locks, or constrain line and arrow angles in 45-degree steps. While drawing or dragging a connector endpoint, near-horizontal or near-vertical alignment snaps to the fixed endpoint's axis and shows a temporary guide. Select an SVG path or freehand stroke to move or delete nodes; SVG node editing supports simple move, line, and close paths. The inspector offers stroke cleanup for near-rectangles, ellipses, lines, and arrows.
- **Document workspaces:** Canvas, Planning, and UI Design are independent workspaces with separate document sessions, models, routes, and formats: `.sketch`, `.sdplan`, and `.sdui`. The centered workspace tabs appear at the top of the desktop welcome content and in the compact workspace header while a document is open. Within an open sketch, a second tab group selects Canvas or Design diagrams in that same `.sketch` document. Windows tabs can switch between open sketches or plans and close them, saving pending changes before a document is replaced or closed. Create or open each format from its workspace, and open registered `.sketch`, `.sdplan`, or `.sdui` files directly from Windows or Android.
- **Project planning:** Keep project notes, prioritized and dated tasks, task checklists, dependencies, milestones, decisions, risks, links, and attachments in a `.sdplan` file. Start notes from Design brief, Requirements, User interview, Meeting notes, or Architecture decision templates. Use the Kanban board, drag tasks between stages, reorder cards, and review dates in Timeline or Calendar. Planning Home includes a task burndown and a count of tasks completed in the last week.
- **File updates:** On Windows, file-watch events detect outside changes to an open `.sketch` file, with a 30-second polling fallback for cloud folders and removable drives. Independent Canvas page and object edits can merge after a provider syncs the changed file; conflicting edits use edit clocks. `.sdplan` files are saved with a baseline check to detect external changes, but they do not use the Canvas background watcher or merge. Android document-provider files do not use background polling. SketchDraw does not host files or live collaboration.
- **Drawing tools:** Click Pen to select the fine pen directly. The separate Paint brushes icon opens Pencil, Soft brush, Marker, Highlighter, and Chalk. Set pen and brush thickness to use presets or fine adjustment; both options work for every drawing style in Properties too. Use a temporary laser pointer, create and fill geometric shapes, crop imported images, and adjust stroke, fill, opacity, corners, and text styling. In full Properties, stroke controls come first, fill type/color/opacity stay together, then shape, label, and text settings follow. The quick-style rail stays hidden when Select, Pan, or Crop is active without a selection. Open Properties to replace the rail with the full inspector for detailed object styling and connector routing.
- **More Tools and toolbar layout:** Fill bucket, Measure distance, Crop image, Edit selected path nodes, Create frame from selection, Code & data, and Paint brushes can be moved between the toolbar and **More Tools**. The More Tools panel keeps a fixed width when brush choices expand. Pen, Brushes, and Eraser stay in sequence when Brushes is on the toolbar; More Tools stays after the stencil library and before history actions. Open **Customize toolbar** to reorder tools, move eligible tools between lists, or hide Undo and Redo; the layout is saved locally.
- **Flowchart symbols:** Build diagrams with process, terminator, decision, input/output, document, multi-document, database, internal storage, preparation, manual input, merge, extract, collate, sort, junction, loop, display, and data-storage symbols. Decorative and general-purpose shapes such as clouds, gears, stars, and crosses are grouped under General. All existing saved shape values remain supported.
- **Shapes palette:** Rectangle, circle, and diamond stay on the toolbar; Triangle is available in Shapes under Basic. Search and switch between Basic, Common, Other, General, or All. The Windows Shapes tool includes Flowchart and General catalogues plus a footer action to spawn every shape on the canvas; phones and tablets keep the basic shape picker compact. The General catalogue includes block arrows, ring, pie slice, wave, banner, teardrop, and funnel. ## Privacy and local data

SketchDraw has no account system, analytics, telemetry, or application service that uploads documents. The app uses Tauri's local filesystem and dialog APIs to open and save files selected by you. It does not send drawing content to SketchDraw servers.

Some app data is kept in local WebView storage on this device:

- Up to eight recent `.sketch` paths and up to 100 recent `.sdplan` paths or Android document-provider URIs, so the launch screen and Planning overview can reopen those files.
- Tool accent and toolbar surface preferences.
- Up to ten named snapshots per sketch path, stored locally for comparison and restore.
- A recovery snapshot for an open `.sketch` canvas document when it has unsaved changes. Recovery data is removed after the document is saved or recovery is discarded; if neither happens, it remains in local app storage. Planning files do not use this Canvas recovery snapshot.

Named versions and recovery snapshots can contain the document's text, shapes, and embedded image data. They are stored locally so a version can be restored or an interrupted session recovered. Other apps or accounts on this device may have access according to the operating system's user-account and device security.

If you save a `.sketch` or `.sdplan` file inside a cloud-sync folder, that folder's provider may upload and process the file under its own terms and settings. SketchDraw does not control that service. Windows can merge independent Canvas edits after a provider syncs them; Planning files use a save-time baseline check and do not receive automatic background merging. Exported files are written to the location you choose. The installer and operating system also have their own download, security, and update behavior; this project does not receive those reports.

The automatic startup check and manual **Check for updates** action contact GitHub for public release metadata. Windows checks the signed updater manifest. Android queries the public Releases API; if a newer APK is available and you choose to install it, the app downloads that release asset to its private cache and hands it to Android's package installer. These requests do not include sketch content, file paths, or drawing data; GitHub receives ordinary network requests under its own privacy terms.

PDF output supports RGB, process CMYK, and grayscale values. It does not currently embed or select a calibrated ICC press profile; confirm color conversion requirements with your print provider.

This description is not a legal certification for every jurisdiction or distribution setup. Data protection obligations can include transparency, purpose limitation, data minimization, retention, and security requirements.
