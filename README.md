# SketchDraw

`This app is made entirely using AI. Use at your own risk.`

SketchDraw is a desktop-first, offline-first drawing and planning app for Windows, macOS, and Linux, with a lightweight Android companion. Canvas drawings and pages are stored in `.sketch` files; Planning notes, tasks, milestones, and project records are stored separately in `.sdplan` files. The welcome screen and workspace navigation provide separate Canvas and Planning viewports, so you can switch between them without closing either document. Save either file locally or in a folder managed by OneDrive, Dropbox, Google Drive, or another sync service.

**App versions: Windows 15.0.0 | Android 10.0.0 | Document format: v2 | Copyright (c) 2026 Toushal Sampat**

> SketchDraw saves remastered version 2 `.sketch` documents for Canvas and version 1 `.sdplan` documents for Planning. It can open legacy `.sketch` versions 9 and 10 and asks before converting them; declining closes the source without saving. Earlier `.sketch` versions are unsupported. The welcome screen switches between Canvas and Planning viewports. With a sketch open, the document tabs switch between Canvas and Design; both views use the same `.sketch` document. Planning opens or creates a separate `.sdplan` file and leaves the sketch open.

## Features

- **Quick text styling:** Adjust text size from the quick-style rail, then open its text-style popover for Bold, Italic, Underline, and all six supported font families.
- **Precision tools:** Use **M** to enter measure mode, then left-click and drag between two canvas points; right-click does not start a measurement and middle-click still pans. **Escape** leaves measure mode. Snapping uses grid, object, and equal-spacing targets; hold **Ctrl** or **Command** to bypass snapping, and hold **Shift** to constrain movement to one axis or preserve proportions while resizing. Select an SVG path or freehand stroke to move or delete nodes; SVG node editing supports simple move, line, and close paths. The inspector offers stroke cleanup for near-rectangles, ellipses, lines, and arrows.
- **Document workspaces:** `.sketch` stores Canvas drawings and Design diagrams on the same pages. With a sketch open, the document tab switcher selects Canvas or Design within that file; Windows document tabs can switch between open sketches and close them. The welcome screen switches between Canvas and Planning viewports, and Planning remains a separate versioned `.sdplan` file. Windows Planning tabs can switch between open plans and close them, saving pending changes before a plan is replaced or closed. Create or open plans from the Planning viewport, and open `.sdplan` files directly from Windows or Android when SketchDraw is registered for that extension.
- **Project planning:** Keep project notes, prioritized and dated tasks, task checklists, dependencies, milestones, decisions, risks, links, and attachments in a `.sdplan` file. Start notes from Design brief, Requirements, User interview, Meeting notes, or Architecture decision templates. Use the Kanban board, drag tasks between stages, reorder cards, and review dates in Timeline or Calendar. Planning Home includes a task burndown and a count of tasks completed in the last week.
- **Canvas and Planning bridge:** Right-click a canvas selection and convert it to a task in the active `.sdplan`; the canvas stores the task reference and shows a check when Planning marks the task complete. Open **Project notes** beside the canvas to edit an active plan note, and select a `[[Component name]]` line to select the matching canvas object.
- **File updates:** On Windows, file-watch events detect outside changes to an open `.sketch` file, with a 30-second polling fallback for cloud folders and removable drives. Independent Canvas page and object edits can merge after a provider syncs the changed file; conflicting edits use edit clocks. `.sdplan` files are saved with a baseline check to detect external changes, but they do not use the Canvas background watcher or merge. Android document-provider files do not use background polling. SketchDraw does not host files or live collaboration.
- **Drawing tools:** Click Pen to select the fine pen directly. The separate Paint brushes icon opens Pencil, Soft brush, Marker, Highlighter, and Chalk. Set pen and brush thickness to use presets or fine adjustment; both options work for every drawing style in Properties too. Use a temporary laser pointer, create and fill geometric shapes, crop imported images, and adjust stroke, fill, opacity, corners, and text styling. In full Properties, stroke controls come first, fill type/color/opacity stay together, then shape, label, and text settings follow. The quick-style rail stays hidden when Select, Pan, or Crop is active without a selection. Open Properties to replace the rail with the full inspector for detailed object styling and connector routing.
- **More Tools and toolbar layout:** Fill bucket, Measure distance, Crop image, Edit selected path nodes, Create frame from selection, Code & data, and Paint brushes can be moved between the toolbar and **More Tools**. Pen, Brushes, and Eraser stay in sequence when Brushes is on the toolbar; More Tools stays after the stencil library and before history actions. Open **Customize toolbar** to reorder tools, move eligible tools between lists, or hide Undo and Redo; the layout is saved locally.
- **Flowchart symbols:** Build diagrams with process, terminator, decision, input/output, document, multi-document, database, internal storage, preparation, manual input, merge, extract, collate, sort, junction, loop, display, and data-storage symbols. Decorative and general-purpose shapes such as clouds, gears, stars, and crosses are grouped under General. All existing saved shape values remain supported.
- **Shapes palette:** Rectangle, circle, and diamond stay on the toolbar; Triangle is available in Shapes under Basic. Search and switch between Basic, Common, Other, General, or All. The Shapes tool includes Flowchart and General catalogues; phones and tablets keep the basic shape picker compact.
- **Modeling palette:** Browse UML, entity relationship, architecture, software, cloud, network, BPMN, data, and UI components. UML relationships include association, dependency, include, and extend; C4 includes code elements and infrastructure nodes; BPMN includes manual, business-rule, send, and receive tasks. Built-in modeling components have editable, type-specific fields separate from their name: API endpoints include method, path, request, response, and authentication; service, database, cloud, network, UML, ER, and BPMN objects expose fields for the information those objects represent. Each component places its relevant details within its own shape, with matching canvas and SVG output. Palette icons use distinct symbols instead of miniature component previews. The specimen catalog includes General and layout components too.
- **ER and UML notation:** ER symbols default to black outlines and text on white fills; change their appearance through Quick Style or Properties. Simple symbols such as use cases and state markers keep their standard geometry, with selection bounds close to the drawn shape.
- **Diagram guides:** Open **Diagram guides** from Canvas Help to browse 19 editable examples across flowchart, UML, ER, BPMN, C4, network, cloud, brainstorming, user journeys, API, data flow, DevOps, and security. Examples include mind maps, use cases, component and deployment views, API authentication sequences, data flows, Git workflows, CI/CD pipelines, and threat models. Each guide includes its purpose, a modeling tip, and a reference; inserted examples use native editable shapes and connectors.
- **Connectors and line styles:** Draw straight, elbow, or curved lines and straight, elbow, curved, or forked arrows. Curves start with a visible bend and one editable control point; add or remove equally spaced points from the route menu. Connectors bind to named north/east/south/west ports or custom connection points on shapes and components, and update when targets move or resize. Custom ports can restrict accepted relationship types; incompatible saved bindings appear in validation, and endpoint dragging skips incompatible ports. Apply solid, dashed, dotted, or double strokes to connectors, shapes, containers, and GUI component outlines. Choose arrowhead styles, drag route handles, enforce elbow-only routing, and reattach nearby dangling endpoints in bulk. Automatic obstacle routing and route optimization use shared diagram geometry on desktop and mobile.
- **Find and replace:** Press **Ctrl+F** to search labels, notes, components, and table names across every page. Open a result to navigate to its page, or replace every matching occurrence inside that object; each object edit remains undoable in its page history.
- **Interactive prototypes:** Link an object to a page, choose an instant, fade, or slide transition in its properties, then click the linked object in presentation mode to follow the flow. Use **Run prototype** in the history toolbar group to test built-in form controls and page links; temporary form changes reset when run mode ends. Frames can also be presented as screens.
- **GUI design:** Open the canvas **View and canvas settings** panel to browse compact controls, app bars, navigation, tabs, cards, and image placeholders. Select a component to edit its title, placeholder, title position, option layout and spacing, navigation items, and card content in the inspector. Position, layout, active-item, and preview choices use direct buttons. Components can be resized to 25 canvas units high when their content fits; content-heavy groups keep their options visible with a content-aware minimum. Create named screen frames, reusable components, arrange a selection, present frames, or export a selected screen. Canvas aids appear first in the scrollable settings panel, followed by fit, structure, and diagram tools; appearance and pen controls are lower in the panel.
- **Frames and containers:** Create named frames from a selection, move their contents together, fit bounds to content, reorder frames, and choose clipping, auto-resize, or a locked size. Groups and containers own their children, including frames and swimlanes. New groups have no border or title by default; toggle either in the quick-style bar or properties. Set the border color, style, and thickness from quick styles or properties. Resizing a group scales its child objects together. Use the component editor to reparent selections and edit custom connection points.
- **Selection and layers:** Move, resize, rotate, group, duplicate, align, and distribute objects. Select connected or similar objects from the command palette. Create per-page layer trees, nest or unnest layers, move selections between layers, and hide, lock, reorder, rename, or delete layers. Save named visibility presets on each page to switch between current and future states. Objects are grouped by drawing tool by default. Undo and redo history is kept per page for the current session.
- **Canvas navigation and snapping:** Pan, zoom, fit the full drawing, or zoom to a selection. Set the board color and paper pattern, use grid and object snapping together, and open Canvas options for an optional minimap and pen input settings. Grid snapping uses a fixed 25-unit document lattice at every zoom and display scale. Moved objects snap to 10-unit increments by default; toggle **Snap moves to 10 units** in Canvas settings. With that option off, the 25-unit grid setting controls movement snapping. Hold Ctrl/Command while dragging to bypass all snapping. Object alignment snapping shows temporary guides across the canvas when moved edges or centers line up. Basic shapes have a 25 × 25 unit minimum; connector width and height show the actual endpoint distance, so one, two, and three grid segments read 25, 50, and 75. The toolbar and quick-style bar stay in their normal positions. Automatic layout is available on desktop and mobile; touch layouts keep advanced tools under More canvas tools, including the spacing control for automatic layout.
- **Pages and project files:** Keep up to 100 named Canvas pages in a compact version 2 `.sketch` file. Planning records live in a version 1 `.sdplan` file; up to 100 recent plan paths are remembered separately from up to eight recent sketch paths. Recent sketch entries are deduplicated across Windows extended-path forms and shown with readable names and locations. Legacy version 9 and 10 sketches can be converted after confirmation; the replacement keeps canvas pages and moves/removes retired notebook and Library records according to the confirmation flow. Rename a sketch from the File menu; the open document, tabs, recent list, and autosave follow its new name. Autosave runs at the chosen 5- or 10-second interval, and Canvas recovery can restore interrupted edits. Desktop SketchDraw archives clean open sketch and Planning documents weekly in app-local `.sdbackup` storage and prunes archives older than 30 days; Android does not create these archives.
- **Text and note cards:** Add plain text, Markdown, tables, code notes, sticky notes, and checklists to the canvas. Markdown supports headings, lists, tables, and syntax-colored code blocks. Select a card or place a new one to edit its content in the compact right-side dock. Resize cards on the canvas, and collapse or expand them with the small card control; collapsed cards retain a short content or task summary.
- **Diagram as code:** Paste Mermaid flowchart or sequence diagrams, preview them, and generate native editable shapes, lifelines, and attached connectors. A persistent source editor appears for selected generated diagrams; it can preview, regenerate with a layout warning, update source from canvas, and copy the code. Mermaid and PlantUML groups keep their source for later editing. Flowchart imports preserve common node/link styles and subgraph grouping; sequence imports support participants and common message arrows. Import supported Mermaid, DOT, D2, CSV, and PlantUML subsets from files. Export editable diagram labels and relationships as Mermaid, DOT, D2, CSV, or PlantUML. D2 currently preserves common node labels, groups, basic shapes, colors, and connectors; other format-specific constructs may be simplified.
- **Code & data tools:** One toolbar entry opens Mermaid and PlantUML generation, CSV charts, schema visualization, and code/data import and export. Link selected canvas objects to a record and value in a local CSV file, or snapshot a public HTTPS JSON endpoint that allows browser CORS. The selected value appears on the object, snapshots and API endpoint URLs are stored in the `.sketch`, and refresh is user initiated. API requests are read-only GET requests without credentials or polling; do not put secrets in endpoint URLs. Direct SQL connections remain unsupported. Export Java or Python starter classes from UML cards, or a Prisma schema from database cards, as a local ZIP. Mermaid, PlantUML, and schema editors show format guidance from an info button. Generated diagrams and simple table-style schema cards keep their source for later editing; selecting a schema card opens its source and live preview in the left panel. Schema cards can resize to a compact width, shortening long labels to fit. CSV charts can be edited later from the chart itself, updating that canvas object. Source panels accept pasted text or local files.
- **Design workspace:** Switch from Canvas to Design to open a searchable, scrollable shape palette with independently expandable groups for Basic shapes, Connectors, Flowchart, Database, Architecture, Software, Cloud, Network, UML, BPMN, Data visualization, Diagram structure, and Text & annotations, plus custom stencils and reusable components. Each modeling component appears in one deliberate group; database services stay with their software or cloud families, while the Database group contains ER symbols, schema tables, views, indexes, and stored procedures. Palette items use compact icon-and-label tiles, and section headings stay visible while scrolling; the mobile palette docks to the left edge and hides its scrollbar. Basic shapes includes primitive and decorative shapes. Connectors includes straight, elbow, and curved lines, solid, dashed, dotted, and double strokes, plus open, filled, two-way, dashed, and dotted arrows used across diagram families. Diagram structure includes reusable frames and swimlanes. Architecture includes C4 people, software systems, external systems, deployment nodes, container and component elements, and enclosure boundaries. UML includes object instances and activity actions, decisions, initial nodes, and final nodes alongside classes, sequence symbols, state machines, and relationships. BPMN includes group artifacts, events, tasks, gateways, data objects, and pools; shared connector presets cover sequence flow, message flow, and data associations. The Design toolbar includes the Canvas view menu for fitting the drawing or selection and changing grid and snap options. Click a shape to add it to the current `.sketch` page. Double-click text or a shape label to edit it on the canvas; select any labeled shape or component to apply font size, family, emphasis, color, alignment, and paragraph formatting directly from the Design toolbar without opening text edit mode. On touch devices, vertical tool layouts place this formatting strip beside the rail with horizontal scrolling. Schema import and export remain in Code & Data, and selecting a schema card opens its source in the left panel for live SQL or JSON edits. The palette or editor stays isolated from the object inspector and can collapse to a reopen arrow. Position and size controls live in a collapsible section in the component editor dock, and expanded editor sections retain their state while the selection updates. Grouped objects keep a tight selection boundary. Switch between Canvas and Design without changing the document.
- **Database schema visualizer:** Paste SQL `CREATE TABLE` statements, JSON table definitions, or JSON Schema object definitions to create editable table cards. Compact cards align field names with their right-aligned types, use close-set plain-text `PK`, `FK`, `NN`, and `UQ` labels, and keep their height tied to the number of fields. Cards can be resized narrower while data types retain space as long as the field name allows. New imports use an automatic ERD layout based on foreign-key links. Connectors attach to the named primary-key and foreign-key fields, show a crow's-foot marker on the foreign-key side, and map each column in a composite key to its matching column. Editing the source keeps existing table positions and resized widths; card heights expand when additional rows need room. Common constraints and indexes are retained in cards and supported exports. Selecting a generated table opens its saved source in the left panel; edits update the linked cards and canvas preview as you type, with one undo step for the editing session. Export table cards as SQL or Draft 2020-12 JSON Schema. SketchDraw `x-` extensions preserve SQL types and key metadata for re-import. This imports schema text; it does not connect to a live database.
- **Modeling components and graphs:** Insert editable UML, sequence, ER, C4, cloud, software, BPMN, and network shapes, plus general-purpose frames and swimlanes. UML includes object instances, activity actions and decisions, activity initial/final nodes, state-machine nodes, component, deployment-node, artifact, and enumeration symbols; BPMN includes message, timer, error, signal, and terminate events, user/service/script/call activities, data stores, annotations, group artifacts, sequence flows, message flows, and data associations; network includes proxy, bridge, bastion, gateway, printer, and workstation. C4 includes people, software systems, external systems, deployment nodes, container elements, and component elements alongside explicit system and enclosure boundaries. AWS, Azure, and Google Cloud libraries include common compute, storage, database, messaging, security, and network services. Provider symbols show labels and readable icon fallbacks while their provider glyphs load, and retain provider artwork in SVG export. Network symbols include gateways, DNS, VPN, internet, modem, and wireless access points; BPMN includes boundary and event gateways and subprocesses. Use **Spawn all components** to place a neatly spaced, labeled specimen sheet on the canvas. Component labels wrap within their symbols with consistent padding. The right-side object details panel starts collapsed, remembers its open or closed state across selections, and can be resized by dragging its side or using the arrow keys; its width preference is saved locally. It keeps named connection point editing, page links, and nested diagrams together, with page navigation collapsed until opened. Links inside grouped objects can be opened directly from the selection. BPMN flows support conditions and default paths; the token simulator follows parallel paths through gateways and waits at modeled joins. Diagram checks include general, BPMN, and ERD profiles. Editable charts include bar, horizontal and stacked bar, line, area, scatter, pie, doughnut, radar, gauge, funnel, heatmap, treemap, and metric cards. Paste CSV into a chart wizard to map label and numeric series columns, or create a chart from schema table metadata or a Markdown note table. Chart editing supports pasted CSV, mixed series types, primary and secondary axes, annotations, palettes, legends, and display settings; series types, axes, and annotation categories use direct buttons. Graphs render directly as shared vectors on the canvas and in SVG export.
- **Reusable component masters:** Turn a selection into a named document master and place linked instances on any page. Edit the master label and ports to update instances, then set per-instance label, color, fill, chart, form, or port-label overrides. Save and switch simple variants, detach an instance, or export masters together with tagged and foldered stencils in a portable library file. Imported master libraries receive new document-local IDs; existing library component groups keep their original behavior.
- **Diagram intelligence:** Choose layered, tree, radial, force, or stress layout for the page or selection and set spacing. Locked objects and layers stay in place. Diagram validation can focus and zoom to a reported object, with optional overlap and empty-label checks. Insert editable UML, ERD, BPMN, C4, and network starter diagrams. Draw.io imports show counts for objects kept, simplified, and skipped; the import supports common shapes, text, styles, connectors, and waypoints, while unsupported format-specific details may be simplified.
- **Import formats:** Import common raster images and SVG artwork. Images are embedded in the `.sketch` file. Common SVG paths, shapes, transforms, nested groups, and gradients import as editable vectors; gradients become representative solid colors. Artwork using unsupported SVG features is retained as sanitized embedded SVG artwork. Select an imported path to edit its path data, fill rule, and optional non-scaling stroke. Import draw.io XML, Excalidraw JSON, CSV, JSON records or graph data, Kubernetes YAML manifests, Terraform resources and module blocks (`.tf` or `.tf.json`), Terraform plan/state JSON, Docker Compose, Ansible, OpenAPI, DOT, Mermaid, D2, supported PlantUML diagrams, CloudFormation/CDK templates, and Azure ARM/Bicep templates as editable canvas objects. Kubernetes policies, ingress resources, and storage references are included where recognized. Infrastructure imports create editable cards and supported dependency links; they do not run the source configuration or deploy resources.
- **Canvas tools:** Search and replace canvas text across pages with Ctrl+F, link an object to another page, validate dangling connector bindings and schema references, reattach nearby dangling connectors, enforce elbow-only routes, save tagged stencil libraries for reuse or export, insert an editable legend or callout, and number selected connectors from top to bottom. While resizing shapes and components, edges snap to the canvas grid when enabled and use 10-unit increments when grid snapping is off; when object snapping is enabled, nearby object edges and centers align as well. Hold Ctrl, Cmd, or Shift to resize without snapping or aspect locking. Custom stencils can prompt for named field values when inserted.
- **Named versions:** Save up to ten snapshots per sketch in local app storage, export or import them as portable files, compare visual page previews and object counts, or restore one as an unsaved change. Snapshots do not sync automatically with the `.sketch` file.
- **Print preview:** Review page size, orientation, margins, page breaks, and tiled layout before printing or saving as PDF. Fit-to-page and poster layouts make it easier to check how a large sketch will be split across sheets.
- **Export:** Review a live preview before exporting PNG, SVG, or PDF. Export the full drawing, current selection, a marquee region, or a selected frame, with configurable padding around drawing, selection, and frame bounds. Set PNG and SVG output dimensions up to 12,000 pixels per side and 60 megapixels total; SVG keeps vector geometry scalable and text as text. PDF supports the current page, all pages, a range, or each frame on its own page, with fit-to-page or tiled output. Exports omit editor overlays. Configure page dimensions, headers, footers, crop marks, bleed, and RGB, CMYK, or grayscale output. PNG and SVG can use transparent backgrounds.
- **Windows workspace:** Windows adds multiple open sketch tabs, customizable shortcuts, the `Ctrl+K` command palette, and a full-screen focus mode. The palette searches tools, components, templates, actions, layout, layers, validation, source editing, view settings, and export; it puts recent commands first and reports shortcut bindings beside matching actions. Selection layout and selection PNG, SVG, or PDF export are available directly from the palette. The toolbar organizer can place Measure, Path editing, and Create frame actions alongside drawing tools or in More Tools. The desktop toolbar groups common tools and keeps object properties close to the canvas.
- **Phone and tablet workspace:** Touch layouts adapt to portrait and landscape and to the chosen toolbar position. Basic tools stay on screen; advanced canvas actions stay collapsed until opened. Tool controls, quick styles, canvas options, page controls, and menus remain reachable by touch.
- **Touch and stylus input:** Draw and edit with a finger or compatible stylus. Use two fingers to pan and zoom, configure gesture actions, and use stylus pressure, tilt, and eraser-end input when the device reports them.
- **Canvas interaction audit:** Run `npm run test:canvas` to exercise drawing and stroke rendering, stylus and touch event handling, anchored zoom and pinch gestures, label bounds, component creation/resizing/serialization/export, vector chart output and chart customization, connector routing, and layout behavior in a local headless Chromium browser. Set `CANVAS_TEST_BROWSER` if Chromium or Edge is installed outside the script's default locations. Stylus and touch checks use synthetic browser pointer input and do not replace testing with physical hardware.
- **Appearance:** Follow the system theme or choose light or dark mode. Both palettes use coordinated surfaces, borders, status colors, and readable input contrast; accent and toolbar colors are adjustable from the app-wide View menu. Modeling components can use the plain style, while visualization graphs always use the modern style.
- **Presentation mode:** Hide the editing interface to present the canvas by pages or named frames. Use the mouse, keyboard, or touch to move between frames and sketch pages.
- **View-only mode and help:** Open a sketch without editing or saving it; the laser pointer and note-card expand/collapse controls remain available. New sketches always start blank. Starter diagrams can be inserted as editable canvas content. Open the in-app guide, Diagram guides, and shortcut reference from Help; they explain drawing, selection, files, pages, export, and diagram ideas.
- **App updates:** SketchDraw automatically checks for updates after startup and notifies you when a newer release is available; you can choose Update or Later. You can also check manually. Windows checks the signed Tauri updater manifest on GitHub. Android checks for a matching arm64 APK, downloads it into app cache if you choose, verifies its package, version code, and signing certificate, then opens Android's installer for your approval. Android does not install updates silently.

SketchDraw does not host online workspaces or live cursors. Canvas file updates use the local `.sketch` path or provider URI and the sync service managing that folder; there is no SketchDraw server or cloud account. Canvas conflicts use last-edit-wins metadata, so devices should have reasonably accurate system clocks. Planning files do not merge offline edits; a save checks whether the `.sdplan` file changed since it was opened.

- **Selected table charts:** Choose **Chart selected table** to load schema field metadata or a Markdown note table into the CSV chart wizard, then choose the label column, numeric series, and chart type before creating the chart.

## Privacy and local data

SketchDraw has no account system, analytics, telemetry, or application service that uploads documents. The app uses Tauri's local filesystem and dialog APIs to open and save files selected by you. It does not send drawing content to SketchDraw servers. If you explicitly link a public JSON API, SketchDraw sends a read-only HTTPS GET request to that endpoint when you connect or manually refresh; the endpoint receives ordinary request metadata, and the returned snapshot and endpoint URL are stored in the `.sketch` file.

Some app data is kept in local WebView storage on this device:

- Up to eight recent `.sketch` paths and up to 100 recent `.sdplan` paths or Android document-provider URIs, so the launch screen and Planning overview can reopen those files.
- Theme and tool accent preferences.
- Up to ten named snapshots per sketch path, stored locally for comparison and restore.
- A recovery snapshot for an open `.sketch` canvas document when it has unsaved changes. Recovery data is removed after the document is saved or recovery is discarded; if neither happens, it remains in local app storage. Planning files do not use this Canvas recovery snapshot.

Named versions and recovery snapshots can contain the document's text, shapes, and embedded image data. They are stored locally so a version can be restored or an interrupted session recovered. Other apps or accounts on this device may have access according to the operating system's user-account and device security.

If you save a `.sketch` or `.sdplan` file inside a cloud-sync folder, that folder's provider may upload and process the file under its own terms and settings. SketchDraw does not control that service. Windows can merge independent Canvas edits after a provider syncs them; Planning files use a save-time baseline check and do not receive automatic background merging. Exported files are written to the location you choose. The installer and operating system also have their own download, security, and update behavior; this project does not receive those reports.

The automatic startup check and manual **Check for updates** action contact GitHub for public release metadata. Windows checks the signed updater manifest. Android queries the public Releases API; if a newer APK is available and you choose to install it, the app downloads that release asset to its private cache and hands it to Android's package installer. These requests do not include sketch content, file paths, or drawing data; GitHub receives ordinary network requests under its own privacy terms.

PDF output supports RGB, process CMYK, and grayscale values. It does not currently embed or select a calibrated ICC press profile; confirm color conversion requirements with your print provider.
